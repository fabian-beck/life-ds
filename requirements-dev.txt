# Tooling for working on scripts/. Not needed to run the generators — install

# black and flake8, so without them validate fails with "No module named black".
# `npm run test:core` and `npm run type-check:py` need pytest and mypy the same
# way.
#
#   .venv/Scripts/python.exe -m pip install -r requirements-dev.txt   # Windows
#   .venv/bin/pip install -r requirements-dev.txt                     # macOS/Linux
#
# Configured in pyproject.toml ([tool.black], [tool.mypy]) and .flake8.
# The tree is formatted with black 26; 25.x and older reformat files nobody
# touched (multiline-string handling changed), which fails `npm run validate`.
